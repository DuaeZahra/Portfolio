# Dua-e-Zahra Naqvi · Portfolio

A coquette-styled, macOS-desktop portfolio: draggable windows, a dock and a menu bar.
Plain HTML/CSS/JS with no build step.

- `index.html`: content (about, experience, projects, AI portfolio, skills, contact)
- `style.css`: the look
- `script.js`: window open/close/drag, dock, clock

**Run locally:** open `index.html` in a browser.

**Live:** https://duaezahra.github.io/Portfolio/ (served from the `gh-pages` branch;
push changes to both `main` and `gh-pages`, or switch Pages to `main` in Settings → Pages).
